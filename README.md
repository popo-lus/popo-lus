## FEATURED PROJECTS

### [FullHan](https://github.com/popo-lus/fullhan-public)

A timetable & assignment tracker for students at The University of Osaka. It auto-generates timetables from KOAN and aggregates CLE assignment deadlines in one place, with class and deadline notifications plus Apple Watch support.

`Flutter` `iOS` `Android`

**[View on the App Store →](https://apps.apple.com/jp/app/id6744124542)**

### [Fujii Photo Calendar](https://github.com/popo-lus/fujii-photo-calendar)

A photo calendar app built with Flutter + Firebase. Supports email sign-up for regular use and invite-code based read-only sharing for guests.

`Flutter` `Firebase`

### [Handai Gourmet Roulette](https://github.com/pochipochi-tsudoi/handai-gourmet-roulette)

A REST API that randomly picks one restaurant around The University of Osaka's Toyonaka campus, using the Hot Pepper Gourmet API as its data source. Built with a clean 4-layer architecture and deployed to Cloudflare Workers (Python Workers).

`Python` `FastAPI` `Cloudflare Workers`
